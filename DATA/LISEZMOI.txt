======================================================================
 CONVERTISSEUR CAO/DAO PAR LOT  —  LISEZMOI
======================================================================

But : convertir par lot, en local et gratuitement, des pièces /
assemblages en STEP + STL et des mises en plan en DWG + DXF (+ PDF), en
pilotant les logiciels de CAO déjà installés via leur automation COM
(pywin32). Aucun convertisseur payant, aucun envoi de fichier en ligne.

----------------------------------------------------------------------
 STRUCTURE DU DOSSIER
----------------------------------------------------------------------
  Dossier principal :
    Convertisseur_CAO.vbs   >>> DOUBLE-CLIC pour ouvrir l'appli (SANS
                            fenêtre de commande) <<<
    DATA\            Dossier de fonctionnement (voir ci-dessous).

  DATA\  (fichiers internes, pas besoin d'y toucher) :
    convertisseur_gui.py    Interface graphique (fenêtre).
    convertisseur_cao.py    Moteur (routage + pilotage des logiciels).
    Convertisseur_CAO.bat        Lancement avec console (voir une erreur).
    Convertir_ici.bat            Lanceur glisser-déposer (optionnel).
    Installer_clic_droit.bat     Ajoute le menu clic droit (optionnel).
    Desinstaller_clic_droit.bat  Retire le menu clic droit.
    Compiler_exe.bat             Fabrique un .exe autonome (optionnel).
    icone.ico                    Icône (raccourci bureau + .exe).
    LISEZMOI.txt                 Ce fichier.

  Astuce : depuis l'écran d'accueil de l'appli, le bouton « Créer un
  raccourci sur le bureau » ajoute une icône de lancement sur le bureau.
  Gardez le .vbs et le dossier DATA ensemble (ne les séparez pas).

----------------------------------------------------------------------
 PRÉREQUIS
----------------------------------------------------------------------
  - Windows.
  - Python 3 (64 bits) installé depuis python.org (inclut tkinter, qui
    sert à l'interface graphique).
  - pywin32 :   py -3 -m pip install pywin32
  - Les logiciels de CAO concernés installés sur la machine.

----------------------------------------------------------------------
 UTILISATION — INTERFACE GRAPHIQUE (recommandé)
----------------------------------------------------------------------
  1. Double-cliquez sur « Convertisseur_CAO.vbs » (aucune fenêtre de
     commande n'apparaît). Un écran d'accueil propose deux outils :
     « Conversion » et « Renommage » (à venir).
     Cliquez « Conversion ». (Le bouton « ‹ Accueil » y ramène.)
  2. « Ajouter des fichiers… » : sélectionnez vos fichiers depuis leur
     emplacement (multi-sélection possible). Ou « Ajouter un dossier… ».
  3. Cochez les formats voulus, dans le cadre correspondant :
       - Pièces        : STEP, STL
       - Assemblages   : STEP, Pièce (assemblage -> fichier .sldprt)
       - Mises en plan : DWG, DXF, PDF
     Les cadres sans fichier concerné sont grisés automatiquement. Les
     cases STEP/STL des « Pièces » et des « Assemblages » sont
     indépendantes.
  4. Nommage (facultatif) : préfixe, suffixe, et numérotation.
       - Numérotation : « Globale » (un seul compteur sur toute la
         sélection) ou « Par type » (compteurs indépendants pour Pièces,
         Assemblages, Mises en plan). Réglez début, nombre de chiffres,
         position (début/fin). Un fichier et ses formats (STEP+STL…)
         partagent le même numéro.
       - Texte par catégorie : un texte propre ajouté aux Pièces, aux
         Assemblages et aux Mises en plan (ex. PC, ENS, PL), plaçable au
         début ou à la fin du nom (Position).
       - Nom commun : s'il est renseigné, il REMPLACE entièrement le nom
         d'origine (renommage complet). Avec une numérotation, des pièces
         de noms très différents deviennent p. ex. carter_001, carter_002…
         Sans numérotation, tous les fichiers auraient le même nom : un
         avertissement s'affiche (risque d'écrasement).
       Un aperçu s'affiche en direct.
  5. Destination :
       - « À côté de chaque fichier » : un sous-dossier « Export » est
         créé à côté de chaque source (par défaut) ;
       - « Dossier personnalisé » : cliquez « Parcourir… » pour choisir
         un dossier de sortie unique.
     Si plusieurs formats sont cochés, chacun est rangé dans son propre
     sous-dossier (STEP/, STL/, DWG/, DXF/, PDF/).
  6. Cliquez « Convertir ». La barre indique l'avancement réel et le
     temps restant estimé ; le journal défile en direct. Un bilan
     s'affiche à la fin (et la liste des fichiers/formats non convertis
     en cas d'échec). Chaque logiciel n'est lancé qu'une seule fois.

----------------------------------------------------------------------
 OUTIL RENOMMAGE (depuis l'écran d'accueil)
----------------------------------------------------------------------
  Renommage par lot, SUR PLACE (le nom d'origine est remplacé),
  applicable à tout type de fichier. L'extension est conservée.

  1. Accueil > « Renommage ».
  2. Ajoutez des fichiers ou un dossier.
  3. Réglez les règles (combinables) :
       - Rechercher / remplacer : PLUSIEURS règles possibles (bouton
         « + Ajouter une règle »), appliquées dans l'ordre. Case
         « supprimer » = retirer le texte trouvé. Case « respecter la
         casse » globale.
       - Préfixe / suffixe ;
       - Nom commun : remplace entièrement le nom d'origine. Combiné à la
         numérotation « Ajouter », renomme tout un lot en nom_001,
         nom_002… (sans numéro, l'aperçu signale les doublons en rouge et
         bloque l'application).
       - Casse (MAJUSCULES / minuscules / Première lettre), espaces -> _,
         retrait des accents. Le nettoyage s'applique à TOUT le nom,
         préfixe et suffixe compris.
       - Numérotation, 3 modes :
           * Aucune ;
           * Ajouter (début, nombre de chiffres, position début/fin) ;
             le numéro se place À L'INTÉRIEUR (après le préfixe ou avant
             le suffixe).
           * Supprimer : détecte une suite de chiffres au début ou à la
             fin du nom et retire UNIQUEMENT cette suite (et son
             séparateur _ - . ou espace). S'il n'y a pas de suite, le nom
             reste inchangé. Ex. « carter_007 » -> « carter »,
             « v2_piece_012 » -> « v2_piece ».
  4. L'APERÇU (ancien nom -> nouveau nom) se met à jour en direct.
     Les conflits sont signalés en rouge : « doublon » (deux fichiers
     auraient le même nom), « existe déjà », « nom vide ». Tant qu'il
     reste un conflit, le bouton « Appliquer » est désactivé.
  5. « Appliquer le renommage » : confirmation, puis renommage en deux
     passes (gère les échanges de noms). Un bilan s'affiche.

  Ordre d'application : remplacements (dans l'ordre) -> casse ->
  assemblage préfixe + [numéro] + nom + [numéro] + suffixe -> nettoyage
  (espaces/accents) sur l'ensemble.

----------------------------------------------------------------------
 UTILISATION — SANS FENÊTRE (optionnel)
----------------------------------------------------------------------
  (Ces lanceurs sont dans le dossier « DATA ».)

  Glisser-déposer :
      Glissez vos fichiers directement sur « Convertisseur_CAO.vbs » (ou
      sur « DATA\Convertir_ici.bat ») : la fenêtre de conversion s'ouvre
      DÉJÀ PRÉCHARGÉE avec ces fichiers.

  Conversion « headless » (sans fenêtre, tous formats par défaut) :
      py -3 convertisseur_cao.py --convert fichier.sldprt dossier\ ...

  Ligne de commande (depuis le dossier « DATA ») :
      py -3 convertisseur_cao.py fichier.sldprt dossier\ ...
      py -3 convertisseur_cao.py --dry-run *.CATPart   (simulation)
      py -3 convertisseur_cao.py --help
      py -3 convertisseur_cao.py            (sans argument = ouvre la fenêtre)

  Clic droit (un fichier à la fois) :
      Double-cliquez « DATA\Installer_clic_droit.bat » (aucun chemin à
      modifier, aucun droit administrateur requis). Ensuite, un clic droit
      sur un fichier CAO propose « Convertir (Convert-Rename) » : la
      fenêtre s'ouvre préchargée avec ce fichier. Pour retirer l'entrée :
      « Desinstaller_clic_droit.bat ».

----------------------------------------------------------------------
 VERSION .EXE  (distribution clé en main, optionnel)
----------------------------------------------------------------------
  Pour distribuer l'appli à des collègues SANS qu'ils installent Python
  ni pywin32 (le logiciel CAO reste requis) :

    1. Sur une machine Windows avec Python, double-cliquez
       « DATA\Compiler_exe.bat ». Il installe PyInstaller au besoin, puis
       compile (1 à 2 min).
    2. Récupérez l'exécutable : DATA\dist\Convert-Rename.exe
    3. Distribuez ce seul .exe. Double-clic = fenêtre d'accueil ;
       glisser-déposer de fichiers dessus = conversion préchargée. Le
       bouton « raccourci bureau » fonctionne aussi depuis l'exe.

  Notes :
    - Un .exe non signé peut déclencher SmartScreen (« Informations
      complémentaires » -> « Exécuter quand même »).
    - Selon la version de pywin32, un « hidden import » supplémentaire
      peut être nécessaire : relancez la compilation en l'ajoutant dans
      Compiler_exe.bat (le message d'erreur indique lequel).

----------------------------------------------------------------------
 CORRESPONDANCES FICHIERS -> LOGICIELS
----------------------------------------------------------------------
      Pièces
        .sldprt / .CATPart / .ipt / .prt . . . . . . . -> STEP + STL
      Assemblages
        .sldasm / .CATProduct / .iam / .asm  . . . . . -> STEP + Pièce
      Mises en plan
        .slddrw / .CATDrawing / .idw / .drw . . . . . . -> DWG + DXF + PDF
      (Creo : fichiers versionnés « .prt.3 », « .asm.12 » gérés.)

      « Pièce » = enregistrer l'assemblage sous forme de fichier pièce
      (.sldprt sous SolidWorks). Cette cible n'est prise en charge que
      pour SolidWorks ; sur les autres logiciels elle est signalée « non
      prise en charge » dans le bilan.
      Après conversion, chaque document ouvert est refermé.

----------------------------------------------------------------------
 ÉTAT PAR LOGICIEL
----------------------------------------------------------------------
  SolidWorks  : TESTÉ ET FONCTIONNEL (pièce .sldprt -> STEP + STL OK).
                Correctif DISP_E_TYPEMISMATCH en place (VARIANT byref sur
                les arguments Errors/Warnings de OpenDoc6 et SaveAs).
                Restent à valider : assemblage, mise en plan (DWG/DXF/PDF).

                Assemblages : export en STEP et en « Pièce » (.sldprt).
                Les documents sont refermés après conversion.
                Note : l'enregistrement d'un assemblage en pièce peut, selon
                la version, ouvrir une boîte d'options SolidWorks ; à valider
                sur un vrai assemblage.

  CATIA V5    : ÉCRIT, à valider. ExportData(chemin, format) ; format STEP
                essayé en "stp" puis "step". Licence STEP requise.

  Inventor    : ÉCRIT, à valider. Traducteurs repérés par GUID puis
                DisplayName ; export via SaveCopyAs.

  PTC Creo    : ÉCRIT, à valider. VB API (Object TOOLKIT, gratuite). Creo
                doit être DÉJÀ LANCÉ et la VB API installée. ProgID de
                connexion variables selon la version (plusieurs tentés).

----------------------------------------------------------------------
 DÉPANNAGE
----------------------------------------------------------------------
  - La fenêtre ne s'ouvre pas : dans le dossier « DATA », lancez
    « Convertisseur_CAO.bat » (ou « py -3 convertisseur_gui.py »)
    dans une invite de commandes pour voir l'erreur. « No module named
    win32com » -> installez pywin32. « No module named tkinter » ->
    réinstallez Python depuis python.org (tkinter inclus).
  - Un logiciel affiche une boîte de dialogue bloquante : traitez ce
    fichier seul pour identifier la cause.
  - Rien ne s'exporte : vérifiez que le fichier n'est pas déjà ouvert et
    verrouillé, et que la licence d'export (ex. STEP CATIA) est présente.
  - Un « KO » dans le journal indique le format et le message d'erreur
    exact : transmettez-le pour diagnostic.
