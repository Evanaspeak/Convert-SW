======================================================================
 CONVERTISSEUR CAO/DAO PAR LOT  —  LISEZMOI
======================================================================

But : convertir par lot, en local et gratuitement, des pièces /
assemblages en STEP + STL et des mises en plan en DWG + DXF (+ PDF), en
pilotant les logiciels de CAO déjà installés via leur automation COM
(pywin32). Aucun convertisseur payant, aucun envoi de fichier en ligne.

----------------------------------------------------------------------
 FICHIERS DU PROJET (à placer ensemble dans un même dossier)
----------------------------------------------------------------------
  Convertisseur_CAO.bat   >>> DOUBLE-CLIC pour ouvrir la fenêtre <<<
  convertisseur_gui.py    Interface graphique (fenêtre).
  convertisseur_cao.py    Moteur (routage + pilotage des logiciels).
  Convertir_ici.bat       Lanceur glisser-déposer (optionnel, sans fenêtre).
  menu_contextuel.reg     Entrées de menu clic droit (optionnel).
  LISEZMOI.txt            Ce fichier.

----------------------------------------------------------------------
 PRÉREQUIS
----------------------------------------------------------------------
  - Windows.
  - Python 3 (64 bits) installé depuis python.org (inclut tkinter, qui
    sert à l'interface graphique).
  - pywin32 :   py -3 -m pip install pywin32
  - Les logiciels de CAO concernés installés sur la machine.

----------------------------------------------------------------------
 UTILISATION — INTERFACE GRAPHIQUE (recommandé)
----------------------------------------------------------------------
  1. Double-cliquez sur « Convertisseur_CAO.bat ». Une fenêtre s'ouvre.
  2. « Ajouter des fichiers… » : sélectionnez vos fichiers depuis leur
     emplacement (multi-sélection possible). Ou « Ajouter un dossier… ».
  3. Cochez les formats voulus :
       - Pièces / assemblages : STEP, STL
       - Mises en plan        : DWG, DXF, PDF
     (les cases inutiles sont grisées selon les fichiers ajoutés)
  4. Destination :
       - « À côté de chaque fichier » : un sous-dossier « Export » est
         créé à côté de chaque source (par défaut) ;
       - « Dossier personnalisé » : cliquez « Parcourir… » pour choisir
         un dossier de sortie unique.
  5. Cliquez « Convertir ». Le journal s'affiche en direct dans la
     fenêtre. Chaque logiciel n'est lancé qu'une seule fois.

----------------------------------------------------------------------
 UTILISATION — SANS FENÊTRE (optionnel)
----------------------------------------------------------------------
  Glisser-déposer :
      Glissez vos fichiers sur « Convertir_ici.bat » (exporte tous les
      formats par défaut, à côté des fichiers).

  Ligne de commande :
      py -3 convertisseur_cao.py fichier.sldprt dossier\ ...
      py -3 convertisseur_cao.py --dry-run *.CATPart   (simulation)
      py -3 convertisseur_cao.py --help
      py -3 convertisseur_cao.py            (sans argument = ouvre la fenêtre)

  Clic droit (un fichier à la fois) :
      Éditez menu_contextuel.reg (remplacez le chemin par votre dossier),
      double-cliquez pour l'importer.

----------------------------------------------------------------------

----------------------------------------------------------------------

----------------------------------------------------------------------
 ÉTAT PAR LOGICIEL
----------------------------------------------------------------------
  SolidWorks  : TESTÉ ET FONCTIONNEL (pièce .sldprt -> STEP + STL OK).
                Correctif DISP_E_TYPEMISMATCH en place (VARIANT byref sur
                les arguments Errors/Warnings de OpenDoc6 et SaveAs).
                Restent à valider : assemblage, mise en plan (DWG/DXF/PDF).

  CATIA V5    : ÉCRIT, à valider. ExportData(chemin, format) ; format STEP
                essayé en "stp" puis "step". Licence STEP requise.

  Inventor    : ÉCRIT, à valider. Traducteurs repérés par GUID puis
                DisplayName ; export via SaveCopyAs.

  PTC Creo    : ÉCRIT, à valider. VB API (Object TOOLKIT, gratuite). Creo
                doit être DÉJÀ LANCÉ et la VB API installée. ProgID de
                connexion variables selon la version (plusieurs tentés).

----------------------------------------------------------------------
 DÉPANNAGE
----------------------------------------------------------------------
  - La fenêtre ne s'ouvre pas : lancez « py -3 convertisseur_gui.py »
    dans une invite de commandes pour voir l'erreur. « No module named
    win32com » -> installez pywin32. « No module named tkinter » ->
    réinstallez Python depuis python.org (tkinter inclus).
  - Un logiciel affiche une boîte de dialogue bloquante : traitez ce
    fichier seul pour identifier la cause.
  - Rien ne s'exporte : vérifiez que le fichier n'est pas déjà ouvert et
    verrouillé, et que la licence d'export (ex. STEP CATIA) est présente.
  - Un « KO » dans le journal indique le format et le message d'erreur
    exact : transmettez-le pour diagnostic.
